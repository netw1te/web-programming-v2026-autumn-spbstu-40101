# Лабораторная работа 3

## Задание

Вариант 8. Реализовать функцию `shuffleArray(arr)`, которая перемешивает
элементы массива в случайном порядке.

## Реализация

Из `solution.js` экспортируется функция `shuffleArray`.

- Используется алгоритм Фишера — Йетса: цикл идёт с конца массива, на каждом
  шаге текущий элемент меняется местами со случайным элементом с индексом от `0`
  до текущего. Так все перестановки равновероятны.
- Функция работает с копией (`[...arr]`) и возвращает новый массив, исходный не
  изменяется.
- Граничные случаи: пустой массив и массив из одного элемента возвращаются без
  изменений (как новые массивы); длина и состав элементов сохраняются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```js
import {shuffleArray} from './solution.js';

shuffleArray([1, 2, 3, 4, 5]); // например, [3, 1, 5, 2, 4]
```
