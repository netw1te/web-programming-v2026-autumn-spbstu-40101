# Лабораторная работа 4

## Задание

Вариант 8. Класс товара и страница «Каталог товаров».

1. Класс `Product` с полями `id` (число), `name` (строка), `categories` (массив
   строк), `price` (число); методы `addCategory(category)`,
   `removeCategory(category)` и геттер `categoryCount`.
2. Функции для массива товаров: группировка по категориям, уникальные категории,
   группировка по диапазонам цен, товары заданной категории, товары с ценой выше
   заданной.
3. Интерфейс: карточки товаров (название, цена, категории), кнопки «Добавить
   категорию», «Удалить категорию», «Добавить товар», «Удалить товар», форма
   создания товара (ID, название, цена), автоматическое обновление интерфейса,
   асинхронные операции через `Promise` + `setTimeout()`, сохранение списка в
   `localStorage`.

## Реализация

- `model.js` — модель и функции коллекций, без обращения к DOM и `localStorage`.
  Экспортируются: `Product` (а также псевдоним `product`),
  `DEFAULT_PRICE_RANGES`, `groupByCategory`, `getUniqueCategories`,
  `groupByPriceRange`, `getProductsByCategory`, `getProductsPriceAbove`.
  - `addCategory` и `removeCategory` возвращают `true`/`false` (пустая или
    повторная категория не добавляется, отсутствующая не удаляется).
  - `groupByPriceRange` принимает необязательный массив диапазонов (`min`
    включительно, `max` не включительно).
  - `getProductsPriceAbove` возвращает товары со строго большей ценой.
- `main.js` — интерфейс и синхронизация с `localStorage` (ключ `products`).
  - Каждая операция (добавить/удалить товар, добавить/удалить категорию)
    выполняется функцией `runOperation`: действие запускается внутри `Promise`
    через `setTimeout` (500 мс); при ошибке (дубль ID, пустое имя, неверная
    цена, категория уже есть / не найдена) `Promise` отклоняется, и сообщение
    показывается в блоке статуса.
  - После успешной операции данные сохраняются в `localStorage` и интерфейс
    перерисовывается.
  - При первом запуске показывается тестовый набор товаров. Из `localStorage`
    данные восстанавливаются как экземпляры `Product`.
  - Результаты группировок из пункта 4.2 при запуске выводятся в консоль.
- `index.html` и `styles.css` — разметка (форма `data-testid="entity-form"`,
  список `data-testid="entity-list"`) и оформление.

## Запуск

Скрипты подключены как ES modules, поэтому страницу нужно открывать через
локальный сервер (например, расширение Live Server в VS Code или `npx serve` в
папке работы): при открытии файла напрямую (`file://`) браузер блокирует
загрузку модулей.
