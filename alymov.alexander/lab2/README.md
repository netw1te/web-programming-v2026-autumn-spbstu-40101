# Лабораторная работа 2

## Задание

Вариант 8. Реализовать функцию `countVowels(str)`, которая возвращает количество
гласных букв (a, e, i, o, u) в строке без учёта регистра.

## Реализация

Из `solution.js` экспортируется функция `countVowels`.

- Строка приводится к нижнему регистру (`toLowerCase()`), поэтому `A` и `a`
  считаются одинаково.
- Символы перебираются циклом `for...of`; гласные хранятся в `Set`, проверка —
  `has()`.
- Граничные случаи: пустая строка возвращает `0`; не строка (например, число)
  приводится через `String()`; согласные, цифры и пробелы не считаются.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```js
import {countVowels} from './solution.js';

countVowels('Hello World'); // 3
```
