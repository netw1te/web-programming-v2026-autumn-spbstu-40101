# Лабораторная работа 1

## Задание

Вариант 8. Сверстать флаг Японии. Красный круг в центре сделать с помощью
`position: absolute`, разместив его точно по центру (он должен оставаться по
центру, даже если увеличить размеры флага). Размеры флага — на усмотрение.

## Реализация

Страница состоит из заголовка и блока `.flag` с вложенным блоком
`.flag__circle`.

- Размер флага задаётся одной CSS-переменной `--flag-width` (по умолчанию
  `450px`), высота считается через `aspect-ratio: 3 / 2`.
- `.flag` имеет `position: relative` и служит точкой отсчёта для круга.
- `.flag__circle` имеет `position: absolute`, `top: 50%`, `left: 50%` и
  `transform: translate(-50%, -50%)`, поэтому его центр всегда совпадает с
  центром флага.
- Диаметр круга — 60% высоты флага (`height: 60%`, `aspect-ratio: 1 / 1`), форма
  круга задаётся `border-radius: 50%`.

## Запуск

Откройте `index.html` в браузере.
